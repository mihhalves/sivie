# SIVIE

Site estático da SIVIE, pronto para GitHub Pages. A coleção usa as fotos normalizadas em `assets/catalogo/` e todos os CTAs de compra abrem uma conversa no WhatsApp da marca.

## Publicar no GitHub Pages

No GitHub, abra **Settings → Pages**, selecione **Deploy from a branch**, e escolha `main` e a pasta `/(root)`. O endereço será exibido pelo GitHub após a publicação.
